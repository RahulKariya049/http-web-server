# Math Behind Machines

A technical blog platform exploring the mathematics behind computer science topics such as cryptography, networking, graphics, algorithms, and machine learning.

Built with semantic HTML and modern CSS.

## Features

- Responsive landing page
- Semantic HTML structure
- CSS Grid & Flexbox layouts
- Featured blog cards
- Reusable article layout

## Tech Stack

- HTML5
- CSS3

## Project Structure

```
index.html
rsa.html
assets/
styles/
```

This frontend is designed to be served by a custom HTTP server built from scratch in C.
